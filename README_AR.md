# NEO TV PANEL

لوحة إدارة وبيع اشتراكات IPTV والسيرفرات والمنتجات الرقمية.

## 1. مميزات المشروع

- لوحة تحكم باللغة العربية من اليمين إلى اليسار.
- إدارة منتجات واشتراكات IPTV.
- إدارة السيرفرات وباقات الموزعين.
- إدارة العملاء والموزعين.
- متابعة الطلبات وحالات الدفع.
- دعم العملتين DZD (الدينار الجزائري) وEUR (اليورو).
- واجهة متجاوبة مع الهاتف والكمبيوتر.
- تسجيل دخول وصلاحيات منفصلة للمدير والموزعين.
- قاعدة بيانات لحفظ المنتجات والحسابات والطلبات.

ملاحظة: بعض الميزات المذكورة تحتاج إلى إكمال برمجتها وربطها بالخادم وقاعدة البيانات.

## 2. متطلبات التشغيل

- Node.js إصدار LTS حديث.
- npm، ويأتي عادةً مع Node.js.
- متصفح حديث مثل Google Chrome.

## 4. تثبيت المشروع

افتح Terminal داخل مجلد المشروع، ثم نفّذ:

npm install

يجب أولًا إعداد ملف package.json بالحزم الصحيحة.

## 5. تشغيل المشروع

بعد إكمال إعداد الخادم والحزم، نفّذ الأمر المناسب الموجود في `package.json`، مثل:

npm start

ثم افتح عنوان الموقع المحلي الذي يظهر في Terminal.

## 6. حماية الحسابات

قبل نشر المشروع على الإنترنت:

- إنشاء حساب مدير آمن.
- تشفير كلمات المرور باستخدام مكتبة موثوقة.
- التحقق من صلاحيات المدير والموزعين على الخادم.
- استخدام قاعدة بيانات دائمة.
- عدم حفظ كلمات المرور أو مفاتيح الخادم داخل ملفات الواجهة.
- استخدام HTTPS عند النشر.
- التحقق من بيانات الطلبات والأسعار على الخادم.

## 7. العملات

يدعم التصميم عرض الأسعار بعملتين:

- DZD — الدينار الجزائري.
- EUR — اليورو.

يجب تحديد سعر الصرف وسياسة التحويل قبل تفعيل التحويل بين العملتين. لا تُعد الأرقام الظاهرة في المعاينة أرصدة حقيقية.

## 8. تنبيه

هذا المشروع قيد التطوير. لا تعتبر الواجهة وحدها نظامًا جاهزًا للبيع أو لإدارة الحسابات.

يجب إكمال الخادم وقاعدة البيانات وتسجيل الدخول واختبارها قبل استخدام بيانات العملاء الحقيقية.
