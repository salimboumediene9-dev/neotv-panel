# NeoTV — بانل تجريبي لبيع خطط السيرفرات واشتراكات IPTV

هذه نسخة أولية قابلة للتشغيل والنشر على Render. الواجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.

## ما الذي يعمل الآن؟
- لوحة رئيسية وإحصاءات توضيحية.
- عرض خطط IPTV والسيرفرات.
- بحث في المنتجات والتنقل بين أقسام اللوحة.
- نموذج طلب تجريبي يرسل الطلب إلى خادم Node.js.
- صفحة طلبات داخل جلسة المتصفح الحالية.
- فحص صحة الخادم عبر `/api/health`.

## مهم قبل استقبال عملاء حقيقيين
هذه ليست بعدُ منصة إنتاج كاملة: لا توجد قاعدة بيانات دائمة، ولا تسجيل دخول/صلاحيات مدير، ولا بوابة دفع، ولا تفعيل تلقائي أو تسليم بيانات اشتراك. لا تضع كلمات مرور أو مفاتيح API في ملفات الواجهة. استخدمها فقط لبيع خدمات تملكها أو لديك تصريح بتوزيعها، ومحتوى IPTV المرخّص فقط.

## تشغيل المشروع على الكمبيوتر
1. ثبّت Node.js إصدار 18 أو أحدث من الموقع الرسمي: https://nodejs.org/
2. فك ضغط ملف المشروع.
3. افتح مجلد `neotv-panel` في Visual Studio Code.
4. افتح Terminal داخل VS Code.
5. نفّذ:
   ```bash
   npm install
   npm start
   ```
6. افتح المتصفح على: `http://localhost:3000`

## النشر على Render
1. أنشئ حساباً في GitHub وأنشئ مستودعاً جديداً باسم `neotv-panel`.
2. ارفع محتويات هذا المجلد إلى المستودع، وليس ملف ZIP فقط.
3. في Render اختر **New +** ثم **Web Service**.
4. اربط مستودع GitHub الذي رفعت إليه المشروع.
5. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
6. اضغط **Create Web Service** وانتظر انتهاء النشر.
7. افتح رابط Render الذي سيظهر لك، ثم أضف `/api/health` في نهاية الرابط للتأكد من أن الخادم يعمل.

لا تحتاج إلى إضافة `DATABASE_URL` في هذه النسخة، لأنها لا تستخدم قاعدة بيانات. عند إضافة PostgreSQL لاحقاً، أضف متغير الاتصال من لوحة Render كمتغير بيئة، ولا تضعه داخل الكود.

## الخطوة التالية للإطلاق الحقيقي
- إضافة PostgreSQL وتخزين المنتجات والطلبات بشكل دائم.
- تسجيل دخول آمن للمدير مع صلاحيات.
- ربط بوابة دفع متاحة قانونياً في بلد نشاطك.
- التحقق من الدفع من الخادم قبل تغيير حالة الطلب.
- إنشاء تسليم آمن للاشتراك/ملفات العميل وسجل تدقيق.
- إضافة سياسة خصوصية وشروط استخدام واسترجاع واضحة.
