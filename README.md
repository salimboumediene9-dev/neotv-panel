# StreamGate — لوحة بيع اشتراكات رقمية (Starter)

مشروع أولي قابل للتشغيل لمتجر عربي RTL مع واجهة متجر ولوحة إدارة، مبني على Node.js + Express + SQLite.

## المتوفر
- واجهة عربية متجاوبة مع الهاتف والكمبيوتر.
- إدارة المنتجات/الباقات وإظهارها أو إخفاؤها.
- تسجيل دخول إدارة مع كلمات مرور مخزنة بـ bcrypt.
- إدارة العملاء والطلبات.
- تأكيد حالة الدفع يدويًا من الإدارة.
- إدخال بيانات الاشتراك يدويًا بعد تأكيد الدفع، وتشفير بيانات التسليم المخزنة باستخدام AES-256-GCM.
- حماية أساسية عبر Helmet وRate Limiting وخصائص جلسة آمنة.
- بيانات أولية تجريبية قابلة للتغيير.

## متطلبات التشغيل
- Node.js 20 أو أحدث
- npm

## التشغيل على Windows
1. فك ضغط المشروع.
2. افتح مجلد `iptv_panel` في VS Code.
3. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
4. غيّر `SESSION_SECRET` إلى سلسلة عشوائية طويلة (32 حرفًا أو أكثر)، وغيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD` إلى بيانات خاصة بك.
5. افتح Terminal داخل المجلد ونفّذ:
   ```bash
   npm install
   npm start
   ```
6. افتح `http://localhost:3000` في المتصفح.
7. لدخول الإدارة اضغط «دخول الإدارة» واستخدم البريد وكلمة المرور اللذين وضعتَهما في `.env`.

## مهم جدًا بخصوص الدفع
هذه النسخة لا تخصم أموالًا ولا تتصل فعليًا ببوابة دفع. واجهة الطلب تنشئ طلبًا بحالة `unpaid` فقط. لقبول البطاقات تحتاج حساب تاجر لدى مزوّد دفع يقبل بلد نشاطك ونوع المنتجات، ثم تنفيذ صفحة دفع مستضافة والتحقق من Webhook موقّع من المزود قبل تغيير الطلب إلى `paid`. لا تخزن أرقام البطاقات أو CVV في هذا المشروع. لا تضع أسرار بوابة الدفع في الواجهة الأمامية.

## النشر
- استضف التطبيق على خدمة تدعم Node.js وملفات تخزين دائمة.
- اضبط متغيرات `.env` في إعدادات الاستضافة، لا ترفع `.env` إلى Git.
- استخدم HTTPS في الإنتاج؛ `secure` cookies مفعّلة تلقائيًا عند `NODE_ENV=production`.
- احفظ مجلد `data/` وملف قاعدة البيانات بنسخ احتياطية منتظمة.
- قبل الاستخدام التجاري، أضف حماية CSRF مناسبة، سجلات تدقيق للإدارة، سياسة خصوصية وشروط بيع، وتحققًا من Webhook الدفع.

## ملاحظات أمان
- بيانات التسليم مشفّرة في قاعدة البيانات باستخدام مفتاح مشتق من `SESSION_SECRET`. إذا غيّرت السر بعد حفظ بيانات تسليم، لن يمكن فك تشفير البيانات القديمة؛ احتفظ به في مدير أسرار آمن.
- هذه نقطة انطلاق تعليمية/عملية وليست مراجعة أمنية مستقلة أو نظام دفع جاهزًا للإنتاج.
- استخدمها فقط لبيع اشتراكات وخدمات لديك حق توزيعها. لا تدرج بيانات وصول إلى خدمات لا تملك تصريحًا بتوزيعها.
